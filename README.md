# NSW Transport Portfolio Performance & Assurance

A multi-source portfolio analysis integrating publicly available NSW infrastructure pipeline, budget and assurance information to improve visibility of transport investment, delivery timelines, published risks and projects requiring management attention.

>[!IMPORTANT]
> This is an independent porfolio project based exclusively on publicly
> available information. It was not commisioned, endorsed or produced by
> Transport for NSW. Any derived classifications or analytical frameworks 
> are the author's own and do not represent official Transport for NSW assessments.
